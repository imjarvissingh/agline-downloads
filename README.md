# AGline downloads

Installers for the AGline desktop app (macOS and Windows). AGline lets your AI agent ring you: https://agline.in

Download the latest build from [Releases](../../releases) and check it against `SHA256SUMS.txt`. Builds are currently unsigned, so macOS and Windows ask you to confirm the first time you open the app.

This repository holds release files only. The application is proprietary and not open source; see [LICENSE](LICENSE).
